## 2023-09-19

블럭종류

일반 블럭 - 공이 한번치면 사라진다

강화 블럭 - 공이 두번치면 사라진다

무적 블럭 - 안사라진다.

아이템 블럭 - 특정 아이템을 떨어트린다.


블럭의 번호를 기준으로 로직을 만든다.

블럭상태

0 이면 블럭없음

1 이면 일반 블럭

2 이면 강화 블럭

10 이면 무적 블럭 

5 이면 아이템 블럭


기본적으로 블럭과 공이 부딫이면

블럭의 상태를 1 감소 시킨다

감소시킨상태를 조건문으로 걸어서 

ex) 

if(brick[i][j] == 0{ 블럭 안그림 }

if(brick[i][j] == 1{ 일반 블럭 그림}

if(brick[i][j] == 2{ 강화 블럭 그림}

if(brick[i][j] == 4){

    brick[i][j] == 0; // 블럭을 그리지 않음
    
    아이템 블럭떨구는 함수.
    
}

if(brick[i][j] == 9{ 

    brick[i][j] == 10; // 블럭상태유지
    


}



블럭의 그림은 switch case문으로 색깔로 표현하면됨



각스테이지는 반복문 별찍기하듯이 구현해도되고


하드코딩해서 다양한 모양으로 발전 시킬수 있다.
