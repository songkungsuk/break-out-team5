# Break-Out 게임 (팀5)

자바스크립트와 HTML5 캔버스를 활용하여 개발된 브레이크아웃 게임입니다. 공을 패들로 튕겨 벽돌을 부수는 클래식 아케이드 게임으로, 다양한 아이템과 기능을 추가하여 게임성을 강화했습니다.

![Break-Out 게임 스크린샷](https://via.placeholder.com/800x400?text=Break-Out+Game)

## 주요 기능

- **3단계의 다양한 스테이지**: 각 스테이지마다 서로 다른 벽돌 배치와 난이도
- **다양한 아이템 시스템**: 
  - 목숨 증가 아이템
  - 파워볼 아이템 (모든 블록을 한 번에 부술 수 있음)
  - 패들 길이 증가 아이템
  - 접착 아이템 (공이 패들에 붙어 있게 됨)
- **다양한 블록 타입**:
  - 일반 블록 (한 번에 파괴)
  - 강화 블록 (두 번 맞아야 파괴)
  - 안 부서지는 블록 (파괴 불가능)
  - 아이템 블록 (아이템 드롭)
- **점수 시스템**: 블록을 부술 때마다 점수 획득
- **생명 시스템**: 초기 3개의 생명, 공이 바닥에 닿으면 생명 감소
- **사운드 효과**: 블록 파괴, 패들 반사, 아이템 획득 등 다양한 효과음

## 게임 플레이 방법

1. 게임 화면 아무 곳이나 클릭하여 게임 시작
2. 마우스를 좌우로 움직여 패들 조작
3. 공이 패들에 닿으면 튕겨나가며, 닿는 위치에 따라 튕겨나가는 각도 변화
4. 모든 블록을 파괴하면 다음 스테이지로 진행
5. 공이 바닥에 닿으면 생명 감소, 생명이 0이 되면 게임 오버

## 기술 스택

- **HTML5**: 게임의 기본 구조 구현
- **CSS3**: 게임 UI 스타일링
- **JavaScript**: 게임 로직 및 동작 구현

## 게임 상세 설명

### 공 반사 메커니즘

- 공이 패들에 맞는 위치에 따라 다른 각도로 반사됩니다.
- 패들의 왼쪽 부분에 맞으면 왼쪽으로, 오른쪽 부분에 맞으면 오른쪽으로 반사됩니다.
- 패들의 중앙에 맞으면 수직으로 반사됩니다.

### 블록 시스템

- **일반 블록**: 한 번 맞으면 파괴되며 10점 획득
- **강화 블록**: 두 번 맞아야 파괴되며 10점 획득
- **안 부서지는 블록**: 파괴 불가능하며 장애물 역할
- **아이템 블록**: 파괴하면 아이템 드롭, 아이템 획득 시 50점 추가 획득

### 아이템 효과

- **목숨 증가 아이템**: 플레이어의 생명 +1
- **파워볼 아이템**: 10초 동안 모든 블록을 한 번에 파괴 가능
- **패들 길이 증가 아이템**: 20초 동안 패들 길이 증가
- **접착 아이템**: 10초 동안 공이 패들에 붙어 있게 됨

### 스테이지 구성

- **스테이지 1**: 기본적인 블록 배치와 몇몇 안 부서지는 블록
- **스테이지 2**: 대각선 형태의 블록 배치와 더 많은 강화 블록
- **스테이지 3**: 체스판 형태의 블록 배치와 다양한 아이템 블록

## 팀원 및 역할

- **hdi**: 스테이지 디자인 및 블록 배치 로직
- **jhj**: 공 이동 및 충돌 감지 시스템
- **isk**: 블록 및 아이템 시스템 구현
- **rsh**: 패들 조작 및 공-패들 충돌 로직
- **sks**: 프로젝트 관리 및 통합

## 개발 노트

- 블록과 공의 충돌 감지 시스템을 세밀하게 조정하여 게임 플레이가 더 정확하고 직관적이 되도록 했습니다.
- 아이템 시스템을 구현하여 전략적 요소를 추가하고 게임의 재미를 높였습니다.
- 각종 효과음과 시각적 효과를 통해 게임에 생동감을 부여했습니다.
- 다양한 블록 배치 패턴을 통해 각 스테이지마다 다른 도전 과제를 제공했습니다.
